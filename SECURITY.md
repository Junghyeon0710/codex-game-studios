# Security

This template executes local tools under the Codex host's permission settings.
Review project config, hooks, scripts, and engine commands before trusting them.
Hooks are guardrails, not a complete sandbox; they do not intercept every write.
Never place credentials in shared project configuration or issue reports.

Report a vulnerability through GitHub private vulnerability reporting when
available. Do not disclose tokens, private transcripts, or game assets publicly.
For ordinary compatibility bugs, open an issue with a minimal reproduction.
