# Quick Start

1. Clone the template and start at its root.
2. Install Python 3.11+, Bash, Git, and your Codex client.
3. Run `python -m pip install -r requirements-dev.txt`.
4. Run `python tools/studio.py doctor` and `python tools/studio.py check`.
5. Open Codex, review project/hook trust, and invoke `$start`.
6. Choose an engine and rigor. The short path is `$brainstorm` → `$create-stories`
   → `$dev-story` → `$story-done`; follow the routing for your chosen settings.

Existing projects: merge the framework directories and AGENTS guidance after
reviewing conflicts. Never overwrite an existing config blindly. Use `$adopt`
to audit compatibility. See the root README and `docs/CODEX-PORT.md`.
