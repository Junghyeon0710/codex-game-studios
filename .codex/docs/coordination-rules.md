# Agent Coordination Rules

1. Directors frame scope and decisions; leads coordinate; specialists implement.
   Use only the roles required by the task, not the whole hierarchy every time.
2. Independent consultations can run in parallel; dependent implementation waits
   for required results. These orchestration workflows request native delegation.
3. State each brief's objective, inputs, allowed files, evidence, and output path.
4. Collect results and verify artifacts before claiming a phase completed.
5. Disagreements return to the shared lead or the user when scope is unresolved.
6. Cross-domain changes need coordination; existing user authorization still applies.
7. Separate file ownership and serialize shared engine/editor/binary-asset writes.
8. Never submit upstream issues, comments, or PRs without the user's authorization.

See `codex-runtime.md` for tools, fallbacks, questions, and host limits.
See `model-tiers.md` for model inheritance. No skill model pin is used.
